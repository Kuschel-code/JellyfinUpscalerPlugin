# AI/ML - ONNX Runtime: do NOT list onnxruntime here.
# The AMD image installs onnxruntime-rocm in Dockerfile.amd, which PROVIDES the
# `onnxruntime` module itself. Installing plain onnxruntime alongside it shadows
# the ROCm build, so the runtime reports AzureExecutionProvider/CPU and the GPU
# is never used (FIX-2 — the real cause of the CPU-only AMD image).
numpy>=1.24.0,<2.0.0

# Capped <4.12: opencv 4.12+ requires numpy>=2. The cap was forced by the old
# rocm/pytorch base (torch 2.3 built against numpy 1.x); the ROCm 7.2.4 base has no
# torch, so it can be lifted - in its own change with a full dry-run (docs/DOCKER-IMAGES.md).
# CVE-2025-53644 (Jpeg2K readHeader) stays open until then - low risk for this service
# (frames are PNG/JPEG, no JPEG2000).
